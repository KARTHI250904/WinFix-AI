# WinFix AI — Security Architecture & Invariants (Phase 22 Production)

## Core Security Invariant

```text
LLM != Windows Shell
LLM != Arbitrary Python
Voice Transcript != Windows Command
Screenshot != Instructions
Knowledge != Windows Command
UI != Execution Layer
```

---

## 1. Zero Shell / Subprocess Execution

* No LLM output is ever evaluated as a shell string, batch script, or PowerShell command.
* WinFix AI uses **0 prohibited AST execution primitives** (`subprocess.Popen`, `os.system`, `os.popen`, `exec`, `eval`, `CreateProcess`, `WinExec`, `ShellExecute`).
* All Windows diagnostics and repairs are hardcoded, allowlisted Python functions utilizing direct Win32 APIs and `psutil`.

---

## 2. Strict Tool Registry Allowlist

Every single Windows operation is strictly registered in the `ToolRegistry`.

* **Total Approved Tools**: 59
* **SAFE (Read-Only Diagnostics)**: 49
* **MEDIUM (Controlled Repairs)**: 10
* **HIGH (Arbitrary / Destructive Actions)**: 0 (Strictly Blocked by SafetyEngine)
* **Aliases / Duplicates**: 0

---

## 3. Cryptographic Confirmation & Replay Protection

All MEDIUM-risk repair operations must pass through the `SafetyEngine`:
1. **Tool Request**: Generated by Agent or User.
2. **Schema Validation**: Parameters type-checked and bounds-validated against `ParameterSpec`.
3. **Cryptographic Token**: A unique, single-use SHA-256 confirmation token is generated and bound to `session_id`, `tool_name`, `arguments`, and timestamp.
4. **User Authorization**: The user must explicitly approve the prompt in the UI.
5. **Replay Rejection**: Tokens cannot be reused or replayed.

---

## 4. Privacy & Data Minimization

* **Logs Sanitization**: All log entries pass through `SanitizingFormatter`, automatically stripping Windows usernames, private user directory paths (`C:\Users\<User>\...`), email addresses, and API credentials.
* **Transient Media**: Screenshots and voice audio streams are processed in RAM and discarded; raw multimedia is never stored permanently on disk.
* **Offline-First**: Zero diagnostic facts, audio recordings, or database records are ever uploaded to external cloud endpoints.
